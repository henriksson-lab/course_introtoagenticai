# Outline: "Describing data before you test it" (one 45-minute lecture)

Example outline for the track "Teaching materials". The agent turns this into
a Quarto reveal.js deck. Audience: first-year students in any science.

1. Problem: a lab group reports "treatment works, p < 0.05", but the plot is a
   bar chart of means with no points. What could be hidden?
2. Centre: mean and median. Skewed data (reaction times). When they differ.
3. Spread: standard deviation vs standard error. What error bars should show.
   Common mistake: SE bars because they look smaller.
4. Show the data: dot plots for small samples; box plots: what each part means.
5. Log axes: equal ratios, equal distances. When to use one.
6. Correlation is not cause: ice cream and drownings; r vs r squared.
7. Checklist for a figure: show points, say SD or SE, label units, say n.
8. Summary table and the three questions to ask of any plot.

Figures I would like (simple, flat, two or three colours):
- the same bar chart hiding two very different dot plots
- a right-skewed histogram with the mean and median marked
- SD vs SE bars for n = 5 and n = 50 from the same population
- a box plot with each part labelled

Speaker notes: 4-6 sentences per slide, what I would say aloud.
